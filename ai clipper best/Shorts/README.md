## Re-run for any video / any channel
```bash
python yt-clipper/brand_render.py clips.json \
   --words words.json --src source.mp4 \
   --config brand/channel.json --outdir Shorts
```
`brand/channel.json` holds logo, colours, fonts, zoom and grade — copy it per channel
(`channel_dkx.json`, `channel_xyz.json`) and pass `--config`. Nothing else changes.

`clips.json` per clip: `{"name","start","end","title","punches":[[t0,t1],…]}`
(`punches` are in clip-relative seconds.)
