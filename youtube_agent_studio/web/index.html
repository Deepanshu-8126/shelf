Setup sequence

One channel first
  1. Copy .env.example to .env.
  2. Add YOUTUBE_DATA_API_KEY for live public market metadata.
  3. Add GEMINI_API_KEY or an OpenAI-compatible endpoint for script drafting.
  4. Install optional dependencies: pip install -r requirements.txt.
  5. Create a Google Cloud OAuth Desktop client; save the JSON as secrets/client_secret.json.
  6. Run python -m agent.auth_youtube --channel ch-1; complete Google consent locally.
  7. Configure voice/audio, review source rights, then test a private upload.
  8. For one market-led draft each day, set AUTO_DRAFT_ENABLED=true and run python -m agent.worker; this does not publish.
  9. Only after tests, set AUTO_PUBLISH_ENABLED=true. Public publishing needs the extra ALLOW_PUBLIC_UPLOAD=true switch.
