# 🧊 Shelf. All-in-One Creator Suite (Chrome / Edge / Brave Extension)

**Version:** 2.0.0  
**Unified Engine:** Combines Product Clipper, Page CSV Scraper, Affiliate Link Batcher & Veo 3.1 AI Video Studio into ONE single extension.

---

## 🚀 1-Minute Installation Guide

1. Open **Chrome**, **Brave**, or **Edge** browser.
2. Navigate to: `chrome://extensions/` (or `edge://extensions/` / `brave://extensions/`).
3. Enable **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** (लोड अनपैक्ड).
5. Select this folder:
   👉 `D:\SHELF_STORE\extension\shelf-all-in-one`
6. Done! Pin the 🧊 icon in your browser toolbar.

---

## 🌟 4 Powerful Integrated Tabs:

### 1. ⚡ 1-Click Clipper
- Automatically detects the active Meesho / Pinterest product.
- Scrapes Title, Price, MRP, Discount, Rating, and High-Res Images.
- Auto-wraps with your verified Meesho Affiliate ID (`374453404`).
- **1-Tap Save:** Add to Shelf Storefront or push to Telegram bot.

### 2. 📊 Bulk Page Scraper
- Scrapes all 20–50 listings on any Meesho search or category page.
- Extracts images, prices, ratings, and creates instant CSV.
- 1-Click Copy or Download CSV.

### 3. 🔗 Affiliate Link Batcher
- Paste multiple Meesho URLs (or load list).
- Converts all links into official `https://www.meesho.com/af_invite/374453404:...` tracking links.
- Export as CSV/TXT.

### 4. 🎬 Google Veo 3.1 AI Studio
- 1-Click trigger for 1080x1920 60fps Full-Motion Veo video generation.
- Choose Mode: `📦 POV Unboxing`, `💃 Model Try-On`, or `🛏️ Multi-Haul`.
- Dispatches directly to your connected Telegram bot (`@Bbyjihotbot`).
