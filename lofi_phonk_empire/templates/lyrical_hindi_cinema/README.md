# 🌊 Template 3: Lyrical Hindi Cinema (Zero Mistake Standard)

## 📌 Overview
Cinematic lyrical video plate engine with 100% natural visuals (zero translucent boxes/overlays), rock-solid typography, and millisecond Whisper lyric synchronization.

## 📐 Dual Format Standards
1. **Vertical 9:16 Full HD (1080x1920)**:
   - Optimized for YouTube Shorts & Instagram Reels.
   - 72pt Dancing Script typography centered at immutable anchor `y = 1000`.
   - Subtle brand tag at `y = 1750`.
2. **Horizontal 16:9 HD (1280x720 / 1920x1080)**:
   - Standard Lyrical Cinema layout at immutable anchor `y = 380`.

## 🛡️ Production Laws (Zero Mistake Mandate)
1. **Official Studio Master Only**: Always strip dialogue and sponsor voiceovers. Audio intro begins clean at 0.0s.
2. **Audio-Slice First, Whisper Second**: Always cut audio first (`ffmpeg -ss ... -t ...`), then feed that exact slice to local Whisper base model. Never estimate timestamps manually.
3. **Zero Black Box Law**: Never draw dark translucent boxes or letterboxes over cinematic video plates.
4. **Gaussian Drop-Shadow Contrast**: High contrast glyph legibility achieved with localized Gaussian drop-shadow (radius 6, dark alpha 240).
5. **Ping-Pong Seamless Loop**: Background video cycles forward and reverse smoothly to eliminate jump cuts entirely.
6. **Cloud-First Render**: Full renders executed on GitHub Actions Ubuntu runners. 0% local laptop heat.
