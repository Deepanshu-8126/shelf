# 🤍 Template 2: White Grid Minimalist Retro Vinyl Engine

## 📌 Overview
Minimalist architectural grid design system with rotating vinyl album disc, audio-reactive waveform, seekbar, and luxury editorial typography.

## 🎨 Visual System & Color Tokens
- **Background**: `#FAF8F4` Warm Ivory Parchment.
- **Architectural Grid**: `#EBE6DE` Soft Crosshairs & Guidelines.
- **Accent Highlight**: `#C8102E` Crimson Red.
- **Typography**: Rozha One (`RozhaOne-Regular.ttf`) for Hindi / Indian song titles.
- **Vinyl Disc**: 360° rotational physics at 33 1/3 RPM with center medallion art.
- **Visualizer**: Real-time audio-reactive spectrum waveform.

## 🚀 Execution Command
```bash
python engine.py --audio "path/to/audio.mp3" --title "SONG NAME" --artist "ARTIST NAME"
```
Supports both 16:9 Widescreen (1920x1080) and 9:16 Vertical Reel (1080x1920).
