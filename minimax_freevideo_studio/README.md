## 🚀 Google Colab Par Kaise Chalana Hai (3 Steps):

### Step 1: Notebook Upload Karein
1. Apne laptop ya phone ke browser me kholein: 👉 **[colab.research.google.com](https://colab.research.google.com)**
2. **Upload** tab par click karein aur is file ko upload karein:
   `minimax_colab_freevideo.ipynb`

### Step 2: GPU Confirm Karein
1. Top Menu: **Runtime ➔ Change runtime type**
2. **Hardware accelerator:** **T4 GPU** select karke **Save** karein.

### Step 3: "Run All" Dabayein (▶️)
1. **Runtime ➔ Run all** (Ctrl + F9) dabayein.
2. 3–4 minute me ComfyUI aur MiniMax FreeVideo engine load ho jayega aur ek **Public URL** milega:
   👉 `https://xxxxx.trycloudflare.com`
3. Us link ko apne 2GB laptop ke Chrome browser me kholein.
4. ComfyUI me **Workflow ➔ Browse Templates ➔ FreeVideo ➔ FreeVideo-All-in-One** template load karein.
5. Prompt likhein aur **Queue Prompt** dabayein ➔ **MiniMax H3 Ultra-Realistic 4K Video Render Ready!**

## ⚡ Colab Auto-Reconnect Trick (Taaki Kabhi Disconnect Na Ho):
Colab tab par `F12` (Developer Tools) dabayein, **Console** tab me jayein aur `auto_reconnect_keepalive.js` ka code paste karke Enter daba dein. Har 60 second me auto-ping karega aur session active rahega!
